HR Analytics Dashboard | Power BI
Overview

This project is an interactive HR Analytics Dashboard developed in Power BI to analyze employee attrition, workforce demographics, salary distribution, and department-level workforce insights.

The dashboard helps HR teams and business leaders identify key factors influencing employee attrition and make data-driven workforce decisions.

Dashboard Preview

Business Problem

Employee attrition can significantly impact organizational performance, recruitment costs, and productivity.

The objective of this project is to:

Monitor employee attrition trends
Identify high-risk departments and job roles
Analyze workforce demographics
Understand salary and education-related attrition patterns
Support HR decision-making through data visualization
